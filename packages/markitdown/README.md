# MarkItDown 2Ways package

This package ships the original one-way `markitdown` API together with the preservation-first `markitdown.twoways` layer maintained in the Nolane-x fork.

For installation, native/derived support matrices, safety guarantees, examples and the v1.0 contract, see the repository documentation:
